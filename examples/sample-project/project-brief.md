# Fictional fixture brief

This is synthetic demonstration material, not a live product specification. The Example Support Desk is a small internal API for accepting and listing support requests in memory. Its only intended users are fictional support staff using a local API client. Persistence, authentication, deployment, retention policy, and a visual interface have not been selected.

## User-specified fixture requirements

- A caller can submit a ticket with a non-empty title and optional description.
- A caller can list tickets created since the current process started.
- Invalid JSON or a missing/blank title is rejected with a client error.

These statements are fixture inputs for the sample, not verified customer requirements.
